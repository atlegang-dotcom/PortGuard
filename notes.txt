PortGuard

A command-line tool that detects TCP port scanning against your device. It monitors incoming SYN packets and tracks how many distinct ports each source IP touches within a rolling time window — the more ports touched in a shorter window, the more aggressive the scan is classified as.

Some legitimate applications do check for open ports as part of normal operation — checking for port 443 to see if you're running a web server, or port 22 before attempting SSH. This kind of legitimate check typically touches only one or two ports, rarely more than 3-5, because a normal application already knows which specific service it needs and has no reason to probe broadly. A device touching many distinct ports on you in a short window has no such legitimate reason — that pattern is reconnaissance, not service discovery, and is the behavior this tool is built to catch.

1. The detector.py file - features 2 functions
- (a) is_scan() function 
  - Decide whether a distinct-port count within a time window counts as a scan.
  - takes in 2 arguments:
    - port_count - number of ports scanned in a time window
    - threshold - number of ports to confirm it is an actual scan
  - The threshold will be set by the user admin, depending on what you consider a potential threat, if the port count is greater than the threshold, then it is a valid reconn scan, function returns true, otherwise false
  - A normal service would typically use not more than 5 ports on your device, and 5 is just strecthing, probably less than 5, however modern day applications could need to run a number of services relying on a number of ports to be open, e.g. a web server app, that sends messages between devices through the SSH protocol, all while saving image, visual and audio data through the ftp protocol, nonetheless, the user will determine the threshold according to the users preference.

- (b) classify_severity() function
  - Classify how aggressive a detected scan is, based on ports-per-second.
  - takes in 2 arguments:
    - port_count - number of ports scanned in a time window
    - window_seconds - the amount of time it took to scann all ports
  - the severity will classfied into 3 categories using the formula - port_count / window_seconds = port scan/sec
    - aggressive - measured if a lot of ports were scanned in a short space of time
    - moderate - measured if a medium level(less than aggressive greater than low) amount of ports were scanned in a less than aggressive greater than low space of time
    - slow - measured if a large number of ports was scanned over quite a long period of time
  - each time taken for each scan doesn't not rule out the potential for it being an attack, even if the ports scanned happened over a long period of time, it just how careful the attacker is - if ever the scan happens to be malicious.

2. The allowlist.py file - features 2 functions
- (a) load_allowlist() function
  - Load a newline-separated file of IP addresses into a set.
  - takes one argument - filepath: of the file containing ip addresses are not a threat to the system
- (b) is_allowlisted() function
  - Check whether `ip` is in `allowlist`.
  - takes in 2 arguments:
    - ip - the ip address to checked if it is in the non threat ip addresses
    - allowlist - the list in a set of allowed ip address that are not considered threats
